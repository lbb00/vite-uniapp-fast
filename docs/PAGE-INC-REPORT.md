| Flag | `BENCH_MODE=page-inc` (baseline mode unchanged) |

**Mechanism (measured):**

1. **Cold:** full uni build; seed per-page SFC template/style hashes + Opt B content fingerprints of script imports.
2. **Warm stable page script edit:** Opt B says import-set + direct-dep content stable → set dirty page → touch sentinel → re-transform `pages-json-js` with **only that page’s** `import('uniPage://…')` (cached importPagesCode filtered) → Rollup generate entry set ≪ N.
3. **Fallback full:** template/style change, import-set change, dep-content change, or any non-page/shared file → clear filter, full importPagesCode.

## Inferred

- Filtering `importPagesCode` to the dirty page **does** cut unrelated page generate (fixture: 1006→8; project: 5658→546) and graph time on project (44s→4.7s).
- On the real **routeA** page, the remaining ~546 outputs are the page’s **component/api/vendor closure**, still generated by Vite/Rollup. That dominates project wall (~50 s outputMs).
- Therefore page-import filtering alone cannot deliver seconds-scale warm on fat pages; need **true Opt C**: page-only emit with `common/*` + existing component chunks **externalized** to on-disk paths (like synthetic `build-incremental.mjs`), bypassing full subgraph generate.

## Unverified

- WeChat DevTools runtime with mid-session `app.js` containing only one `if (!Math)` page string (other page files remain on disk via `emptyOutDir: false` / `app.json` routes).
- Byte-identical page JS vs full uni emit on project routeA.
- Combining page-inc with write-skip `fs` mode on project outputMs.
- Template-only / style-only edit paths beyond unit logic (fixture script path + component full fallback measured).

| Overall | Wiring is real and falsifiable; fixture proves the approach; project needs externalizing Opt C for wall-clock success |

## Next concrete step

Implement a **page-only Rollup/Vite transform pipeline** for eligible edits that:

1. Reuses uni/vue transforms for the single dirty `.vue`
2. Externalizes `common/vendor`, `common/assets`, and already-emitted component chunk paths from cold dist
3. Writes **one** `pages-tab/routeA/index.js` (WXML/JSON untouched)
4. Skips Vite full rebuild (cancel/ignore watch rebuild when Opt B says incremental)

Success gate: project script1 wall **≪ 10 s** with `generated≈1`, `pageEditPresent`, other pages untouched, and a recorded full fallback on shared-module edit.
